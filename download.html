⬇ অ্যাপ ডাউনলোড (APK) সব ভার্সন দেখুন
ইনস্টল করার নিয়ম
  1. উপরের বাটনে APK ডাউনলোড করুন
  2. Settings → Install unknown apps চালু করুন
  3. ডাউনলোড করা ফাইল ওপেন করে Install চাপুন
  4. নোটিফিকেশন Allow দিন
  5. Battery → Unrestricted রাখুন
